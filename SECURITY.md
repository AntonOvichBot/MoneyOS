# Security Policy

## Reporting a vulnerability

If you discover a security issue in MoneyOS, please do not report it in a
public GitHub issue.

Instead, email the maintainer at `jack@nikogosian.com` with:

- A short description of the issue
- Steps to reproduce it
- The affected version or branch, if known
- Any suggested mitigation, if you have one

## What to expect

- We will aim to acknowledge reports within a reasonable time
- We may ask follow-up questions to reproduce and validate the issue
- Once confirmed, we will work on a fix and decide on disclosure timing

## Scope

This policy covers the MoneyOS repository and packages in this repo.

## Please avoid

- Posting exploit details in public issues before a fix exists
- Sharing private keys, seeds, API keys, or other secrets in reports
