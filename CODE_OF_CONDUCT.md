# Code of Conduct

## Our standard

MoneyOS is an open source project, and we want it to feel serious, respectful,
and safe to contribute to.

Examples of behavior that helps create that environment:

- Being respectful in disagreement
- Giving technical feedback without personal attacks
- Assuming good intent while still being honest and specific
- Welcoming newcomers and basic questions
- Focusing on what improves the project

Examples of unacceptable behavior:

- Harassment, insults, or demeaning language
- Personal attacks or hostility
- Deliberate intimidation
- Publishing someone else's private information without permission
- Repeated bad-faith disruption of issues, pull requests, or discussions

## Scope

This code of conduct applies in project spaces, including GitHub issues, pull
requests, code review, and other public project communication.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, issue
titles, pull requests, and other contributions that do not align with this code
of conduct.

## Reporting

If you experience or witness unacceptable behavior, please contact the
maintainer at `jack@nikogosian.com`.

## Project stance

We want MoneyOS to be technically sharp and pleasant to collaborate on.
Professionalism matters here.
